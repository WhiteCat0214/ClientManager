# Mabinogi Client Manager

GitHub：<https://github.com/WhiteCat0214/ClientManager>

瑪奇 (Mabinogi) `Client.exe` 的常駐管理工具 (顯示於通知區域)。

> 這是非官方的第三方工具，使用前請閱讀最後的[免責聲明](#免責聲明)。

## 主要功能

- 視窗無邊框 / 鎖定大小位置 / 還原 (類似 Kisara 的偽全屏)
- 限制CPU使用率 (類似 BES, Battle Encoder Shirase 的CPU限制軟體)
- 優先權與親和性設定 (類似 Process Lasso 的程式優先權及CPU親和性的調整)
- 效能監控 (類似 XBOX Gamebar 的效能監控，另外加上資源監視器的網路TCP連線延遲資訊)

## 下載與建置

- **下載：** 到本倉庫的 [Releases](https://github.com/WhiteCat0214/ClientManager/releases) 頁面下載壓縮檔，內含 `ClientManager.exe` 與含完整說明的 `ClientManager.ini`。
- **自行建置：** 需要 Visual Studio 2022（工作負載：使用 C++ 的桌面開發）或 Build Tools。雙擊 `build.bat`（會自動要求管理員權限），完成後得到 `ClientManager.exe`。

## 啟動

- 執行 `ClientManager.exe`（需要管理員權限），程式會常駐在右下角的通知區域。
- 在通知區域的圖示上按右鍵開啟選單；連點兩下圖示的動作可在選單設定 (預設為切換無邊框 / 還原)。
- 把滑鼠停在圖示上，會顯示遊戲目前實際的 CPU / GPU / I/O 優先權、CPU 核心，以及是否正在限制中。
- 使用前請先手動啟動一次遊戲，工具才能找到 `Client.exe` 並記住它的路徑與啟動參數。

## 選單功能

### 切換無邊框 / 還原

把遊戲視窗切換成無邊框 (鋪滿所在螢幕的工作區，不含工作列)，再按一次還原。

### 鎖定視窗大小及位置

移除縮放邊框與最大化按鈕，標題列右鍵選單的「移動」變灰，並且無法用滑鼠拖曳視窗。鎖定只在套用時改變一次視窗樣式並取消滑鼠拖曳，不會持續重設視窗的大小與位置。

### 重置視窗大小和位置

把視窗還原成有邊框，並回到上一次的視窗化位置；沒有紀錄時置中 1280x720。

- 遊戲重啟後，無邊框與鎖定會自動重新套用。CPU 限制中調整視窗時，會先短暫解除限制，完成後自動恢復。
- 遊戲自己改變視窗後 (例如在遊戲的環境設定按取消)，會依目前的模式還原：無邊框模式重新鋪滿螢幕工作區；一般視窗只把縮放邊框的樣式改回去，不會動視窗的大小與位置。

### 隱藏遊戲工作列

隱藏遊戲在工作列上的按鈕，不改變視窗本身 (勾選時為隱藏)。設定會儲存，遊戲重啟後自動套用；結束本工具時會先恢復工作列按鈕。

> 注意：隱藏後，視窗最小化時無法從工作列點回來 (搭配 CPU 限制的「僅在視窗最小化時」要特別注意)，可先取消勾選「隱藏遊戲工作列」讓按鈕回來。

### 遊戲優先權 / 親和性

類似 Process Lasso，只針對 `Client.exe`，偵測到遊戲啟動後自動套用，並持續確認。

| 項目 | 說明 |
| --- | --- |
| CPU優先權 / GPU優先權 | 即時 (Realtime)、高、高於標準、標準、低於標準、低 (Idle)（由高到低） |
| I/O優先權 | 高、正常、低、極低 |
| CPU親和性 | 列出所有邏輯核心 (核心 0 ~ N)，後面註明核心類型 (大核 / 小核 / 超執行緒 / 實體核心)，勾選要讓遊戲使用的核心 (每按一次切換一個)。最上方有「全選」「僅大核」「僅大核 (P-core) 不含超執行緒」「僅小核」可快速設定。沒有大小核的 CPU 則提供「全選」與「僅實體核心 (不含超執行緒)」。至少要保留一個核心。 |
| 於工具提示顯示目前狀態 | 在通知區域圖示的提示中顯示遊戲目前實際的優先權與親和性 (預設勾選)。 |

運作方式：

- 第一次偵測到遊戲執行時，會讀取遊戲「目前」的設定並存進設定檔，選單會顯示打勾。
- 之後在選單修改，設定會存檔，並立即套用到執行中的遊戲；以後每次遊戲啟動也會自動套用。
- 若遊戲正處於 CPU 限制 (已降低優先權) 的狀態，修改的優先權會在解除限制後才套用。
- CPU 親和性只對記錄它的那台電腦有意義：設定檔搬到不同 CPU 時，會自動重設並通知。

> 注意：即時優先權可能影響系統回應，請謹慎使用。

### 限制CPU使用率

在不需要全速運作時 (例如最小化或掛機)，讓遊戲只用很少的 CPU。

| 項目 | 說明 |
| --- | --- |
| 啟用CPU限制 | 總開關。關閉時下面的設定都不會作動。 |
| 限制時同時降低優先權 / 節能模式 | 限制生效時，把遊戲的 CPU 優先權、GPU 優先權降為最低、I/O 優先權降為極低，並啟用節能模式；解除限制後還原成上面「遊戲優先權」的設定值。(預設啟用) |
| 生效條件 | 永遠 / 僅在視窗最小化時 / 僅在視窗最小化或於背景執行時 (預設：僅在視窗最小化時) |
| 限制比例 | 30% ~ 98%，代表暫停遊戲的時間比例，越高越省 CPU 但遊戲越不流暢。 |

限制生效期間，通知區域圖示與遊戲視窗 (工作列) 的圖示會變成藍色，解除後換回。

### 效能監控

選單有三項：「啟用監控」、「鎖定位置 (滑鼠穿透)」、「監控設定...」。

在遊戲畫面上顯示文字疊加視窗，項目依序為 CPU、RAM、GPU、VRAM、FPS、Latency (標籤固定為英文)：

| 項目 | 說明 |
| --- | --- |
| CPU | 遊戲的 CPU 使用率 (以全部核心為 100%) / 目前時脈；CPU 限制中時，後方會加註「(限制中)」 |
| RAM | 遊戲的私有工作集 (同工作管理員「記憶體」欄位) 佔實體記憶體的比例 / MB 數 |
| GPU | 遊戲的 GPU 使用率 |
| VRAM | 遊戲使用的專用顯示記憶體佔顯示卡總量的比例 / MB 數 |
| FPS | 每秒畫面數 (支援 D3D9 與 D3D10 / 11 / 12) |
| Latency | 遊戲與伺服器之間的網路延遲 (同資源監視器「TCP 連線」的延遲)；登入畫面顯示登入伺服器的連線，進入遊戲後顯示分流伺服器的連線 |

百分比為整數時不顯示小數，否則顯示到小數第一位 (例如 8% 與 12.3%)；資料不可用時顯示 `--`。

**監控設定視窗：**

- 啟用監控 (最上方)
- 顯示項目：CPU / RAM / VRAM 可分別選擇顯示「比例」與「實際值」，預設只顯示比例；右側「顯示順序」框可用滑鼠拖曳調整
- 顯示設定：排列方式 (直式 / 橫式，橫式可設定分隔文字)、更新頻率、CPU 使用率算法 (週期法 / 時間法 / 估算)、Latency 取樣方式 (最近一次樣本值 / 平滑往返時間)
- 外觀：字體大小、字體顏色、文字外框顏色、不透明度、背景顏色、鎖定時無背景
- 只在遊戲前景時顯示 (預設不勾選)、鎖定位置、重置位置
- 視窗開啟期間監控畫面會固定顯示 (沒有遊戲時以示範數值預覽)，方便調整外觀。
- 「套用」立即變更監控畫面；「確定」才寫入 ini；「取消」回復成開啟視窗之前的狀態。
- 顏色請輸入 6 位數 HEX (例如 `FFFFFF`)。下拉選單只列出常用的值，ini 設成其他合法值時會保留原值。
- 未鎖定時可用滑鼠拖曳到想要的位置；鎖定位置後滑鼠會穿透視窗，要解鎖只能從選單或設定視窗。

### 強制重啟 / 結束遊戲

| 項目 | 說明 |
| --- | --- |
| 重啟遊戲 (Client.exe) | 結束遊戲後用最後一次的路徑與啟動參數重新開啟 (不含官方網頁登入器的 `/N:` `/V:` `/T:` 參數)。 |
| 重啟遊戲 (Mabinogi.exe) | 結束遊戲後改開同資料夾的啟動器。 |
| 強制結束遊戲 | 立即結束 `Client.exe`。 |

遊戲沒有在執行時，會使用最後一次記住的路徑 (沒有紀錄時嘗試 `C:\Nexon\Mabinogi\Client.exe`)。

遊戲未啟動時，無邊框 / 鎖定 / 重置 / 隱藏遊戲工作列 / 強制結束與連點圖示會顯示「遊戲未啟動」的提示；已記錄過遊戲路徑與啟動參數時，提示視窗會多出「重啟 Client.exe」「重啟 Mabinogi.exe」兩個按鈕。

### 語言

自動選擇 / 繁體中文 / 简体中文 / 英文 / 日本語。優先讀設定檔的語言；設定為自動時依系統語系選擇。

### 關於

顯示程式說明，下方的「診斷記錄」顯示 CPU 各算法的並列數值、遊戲的 TCP 連線與往返時間、FPS 事件統計 (每秒自動更新，不寫入檔案)，回報問題時使用。

- 複製：立即複製目前的記錄
- 停止更新 / 自動更新：手動暫停或恢復更新
- 在記錄區塊內選取文字、或捲動捲軸時也會暫停更新，捲回最上方 / 最左邊並取消選取後才恢復自動更新。
- 診斷記錄只在關於視窗開啟期間收集，關閉視窗就停止。

## 設定檔

`ClientManager.ini` (與 `ClientManager.exe` 同一個資料夾)，每個數值都標註了功能、可調整範圍與預設值。程式會記住選單設定、遊戲路徑與啟動參數 (官方網頁登入器帶入的 `/N:` `/V:` 臨時登入帳號密碼與 `/T:` 參數不會被儲存)。(設定檔內的說明文字為繁體中文。)

- Release 壓縮檔內已附上含完整說明的 `ClientManager.ini`。
- 倉庫內含完整說明的預設檔名為 `ClientManager.default.ini`；自行建置時，複製為 `ClientManager.ini` 放在 exe 旁即可。沒有設定檔時，程式會使用預設值並自動建立 (不含說明文字)。
- 設定檔會記錄遊戲路徑與啟動參數；官方網頁登入器帶入的 `/N:`、`/V:` (臨時登入帳號密碼) 與 `/T:` 參數不會被儲存。分享或上傳設定檔前，仍建議先確認內容。

## 其他

- 若同時用 Process Lasso 管理 `Client.exe` 的優先權，請擇一使用，避免互相覆蓋。
- 若工具被強制結束而遊戲停在暫停狀態，重新執行 `ClientManager.exe` 或執行 `ClientManager.exe /resume` 即可解除。
- 透過官方網頁登入器啟動遊戲時帶入的 `/N:`、`/V:` (臨時登入帳號密碼) 與 `/T:` (橘子標誌，通常為 `/T:gamania`) 參數，不會儲存到設定檔，重啟遊戲時也不會帶入。因此用重啟遊戲的方式不會直接進入遊戲，請改用第三方登入器獲得登入帳號密碼後進行登入，或是結束遊戲後自行透過官網啟動遊戲。
